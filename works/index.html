開発実績

FarEdge Labs の設立は2026年7月29日で、ここに並ぶのは会社としてではなく代表エンジニア個人の実績です。受託・常駐・在籍先いずれの形態でも他社の案件のため、社名はコンプライアンス上お出しできません。今後、Web への掲載をご承諾いただいた顧客については社名を開示していきます。

稼働中

  • 機械学習モデルの構築と量子化、アプリケーションへの実装

    モデル開発から量子化、実際に動くアプリへ載せるところまで。特徴量設計とデータパイプラインの構築も担当。

  • オンラインスポーツシミュレーションゲーム — テックリード

    開発チームを率い、アプリケーションから実行基盤まで。インフラをサーバーレス化し、同時アクセス耐性を強化しつつ運用コストを60%削減。

  • コーポレートサイトと社内クラウド基盤（このサイト）

    Next.js の静的書き出し、WebGL / GLSL によるハーフトーン描画、GCP のサーバーレス関数を Terraform で全面 IaC 化。人物に話しかけると全二重の音声対話が始まる — 音声モデルと推論モデルを分離し、関数は SDP を中継するだけなので、会話が何分続いても自前のインフラは経路に入らない。CI からのデプロイは Workload Identity Federation でキーレス化し、長期の認証情報を置いていない。

これまで

  • 大手自動車メーカー向けシステム開発

    運転診断・道路情報 API・保健連携のフルスタック開発。IaC 化の基礎を作ったチームの一員として、開発基盤から実行基盤まで AWS 上のアーキテクチャを再設計し、監視とアラート、クロスアカウントでの大規模データ移行も担当。PO に出した改善案が採用され、実装まで任された。Tomcat / Java 8 の常駐構成から段階的に移行して常駐インスタンスを無くし、最後の一段は計測で決めている — 実装言語を Java から Python へ替えると実行メモリが半分以下になり、Lambda はメモリ×時間で課金されるので規模が出るほど効いた。

  • ホテル向けサポート AI と自動チェックイン

    チェックイン2日前に送るハッシュ入り URL をクリックするだけで JWT 認証が通り、宿泊客にアカウントを作らせない。身分証の画像は AppSync 経由で S3、宿泊者情報は DynamoDB、いずれも KMS で暗号化し、旅館業法が求める本人確認を無人で満たす — ただし照合の最終承認だけは人間に残した。サポート側は RAG と Tool Calling（並列実行）の AI Agent で、対応しきれないケースは人へ引き継ぐ。

  • エッジ AI 推論の性能検証 PoC

    組込み向け AI アクセラレータの公称性能が実ワークロードで成立するかの検証。INT8 量子化（PTQ / QAT）から ONNX 変換・推論実行・計測まで担当し、カタログ値ではなく計測値で採用可否の判断材料を出した。

  • 社内向け業務管理システム

    勤怠・目標設定・給与明細の電子化。データベースは新設せず、既に社内で回っていた Notion の運用に合わせて Notion API を採用した。テックリードとして要件定義からタスク分解、開発チームへの割り振りと進捗管理まで担当。

  • 暗号資産の価格予測モデル PoC

    Transformer によるマルチステップ予測を TensorFlow で構築。複数の特徴量構成を比較検証し、寄与が確認できなかったニュース特徴量は不採用と判断した。

  • 大手メタバースの保守と機能開発

    性能試験・負荷試験の全自動化を提案・主導。FastAPI による試験自動化基盤、結果の S3 自動転送、CloudWatch ログのグラフ化とレポート自動生成まで一気通貫で整備。

  • 農業圃場スコアリング PoC

    Google Earth Engine で Sentinel-2 の NDVI と SAR を取得し、圃場単位のスコアリングを設計。特性の異なる観測データを組み合わせ、雲で欠ける光学データを補完する前処理を組んだ。

  • 眼科医師向け質問応答 AI

    医療論文の Embedding と知識ベース構築、Vector Search による回答生成。初期は BERT を Fine-tuning したが、精度ではなく実行速度と運用コストが制約と判断して外部 API へ移行。

  • サーバーレス CMS

    React / Vite と AWS CDK。案件発足当初は AppSync を使っていたが、GraphQL レイヤを挟まないほうが課金も構成も軽いと判断して切り替え、API Gateway から Lambda を呼んで DynamoDB と S3 で完結させた。WordPress に依存せず CMS 相当の機能を実現し、編集しやすいテンプレートとして納品。

  • 社内システムのクラウド移行と生産管理基盤の構築

    医療機器メーカーで、オンプレミスからクラウドへの全面移行を担当。ファイルサーバーを AWS FSx へ移し、生産管理システムは権限ベースのアクセス制御込みで新規構築。CloudFront + WAF + ALB をプライベートサブネットに置くエントリポイント設計も。
